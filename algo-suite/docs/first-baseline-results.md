# First real baseline results (price-only)

The first end-to-end run of the price pipeline on **real Dukascopy data** — the execution
pass that exercises every built stage (`algo-download → algo-transform → algo-backtest
materialize → experiment run → algo-analyze summary`) instead of test fixtures. These are
**price-only** baselines; at the time of this run the AI news/sentiment hybrid was later
work gated on `algo-score`. No number here is an AI result.

> **Update (2026-09-26):** the hybrid strategy (F1–F7 filter chain, `algos/hybrid`) is now
> built and runs in the real LEAN container (Spec 04h) — see `ch04-deliverables.md` and
> `docs/stories/done/2026-09-26-04h-algo-backtest-hybrid-integration/`. This record is kept
> as-is: the price-only baseline this hybrid must still beat on a real, wider window
> (Spec 06/08, in progress).

> **Scope of this record.** This preserves the **reported result + provenance** (the table
> below, the data window, and the exact commands). It is **not** an archive of the raw run
> artifacts — `run.json` / `trades.json` / `metrics.json` / `summary.csv` / lean-data live
> under the gitignored `data/` tree and are **regenerated by re-running** the commands at
> the bottom; they are not committed.

## Window & data

- Instrument: **EUR/USD**, minute bars, OANDA market (LEAN).
- Source: **Dukascopy** ticks for **2024-06** → 1,334,494 ticks → 28,714 minute QuoteBars
  (483 real hours downloaded, 237 weekend/holiday empties, 0 failed; 0 quarantined on
  transform; 25 trading-day lean-data zips materialized).
- Backtest window: **2024-06-03 → 2024-06-28**, $100k cash, long-only, single position,
  fixed sizing 0.5. Spec: `experiments/baseline-comparison.yaml`.

## Results (`algo-analyze summary`)

| run | strategy | params | closed trades | total return | Sharpe | max drawdown | hit rate |
|---|---|---|---|---|---|---|---|
| ma-eurusd-2024-06 | baseline-ma | fast 20 / slow 60 | 288 | −0.0095 | −9.59 | 0.011 | 0.264 |
| meanrev-eurusd-2024-06 | baseline-meanrev | window 60 / band 0.0015 | 6 | −0.0018 | −14.60 | 0.003 | 0.167 |

## Reading (honest)

- **Both baselines lose money** over the month (negative return, hit rate well below 50%).
  Expected: these are naive price-only rules with no real edge, and every trade pays the
  bid/ask spread. `baseline-ma` (20/60-min crossover) **over-trades** — 288 round trips in a
  month — so spread drag dominates. `baseline-meanrev` trades rarely (band seldom hit), so a
  small loss.
- **Sharpe is not meaningful at one month** (tiny sample → extreme values). The thesis uses
  longer windows and proper **deflated Sharpe + Monte-Carlo Permutation Test** in the
  analysis phase; these figures are a pipeline proof + order-of-magnitude sanity, not the
  final result.
- These params are arbitrary-but-reasonable first values, **not tuned**. The point of the
  execution pass is that the *pipeline produces real, reproducible numbers* — and it does.

This establishes the **price-only baseline the AI hybrid must beat** (thesis hypothesis H1).

## Reproduce

```bash
cd algo-suite
export ALGO_DATA_ROOT="$PWD/data"
uv run algo-download  run --source dukascopy --symbol EURUSD --month 2024-06   # network
uv run algo-transform run --source dukascopy --symbol EURUSD --month 2024-06
uv run algo-backtest  materialize --symbol EURUSD --year 2024 --month 6
uv run algo-backtest  experiment run --spec experiments/baseline-comparison.yaml  # Docker/LEAN
uv run algo-analyze   summary    # -> data/analysis/summary.csv
```
