# Hardener evidence

The final gate killed **174 of 174 mutants**, with zero surviving mutants,
errors, exemptions or claimed equivalents. The final unmodified suite passed
174 BDD scenarios. A negative control replaced the copied DSR result with
`-9999.0`; the CLI probability assertion failed, establishing that the test
process exercised the copied production code.

The scope is every mutant generated by the repository's
`tools/mutation_harness.py` over `deflated.py`, `significance.py`, `portfolio.py`
and `reports.py`. Operators are simple comparison inversion (`<`, `<=`, `>`,
`>=`, `==`, `!=`), `and`/`or` inversion, `not` removal, and arithmetic inversion
(`+`/`-`, `*`/`/`). There was no numerical cap or sampling. This is exhaustive
for those operators; it does not claim all possible program transformations.

Each mutant ran in an isolated copied source/test tree with bytecode caching
disabled. The source workspace was never mutated. Test-process timeouts are
inconclusive errors, never kills. Runs use two workers; each test process has
120 seconds. The recorded production SHA-256 hashes bind outcomes to source.

The third pass reran every mutant in the changed significance module and the
remaining two survivors in unchanged modules; it retained 100 prior kills only
where whole-file hashes matched. The fourth pass replayed the last survivor and
retained 148 hash-matched kills. The review follow-up changed `deflated.py`,
`portfolio.py` and `reports.py`, so every mutant in those files (114) ran fresh;
the 47 `significance.py` kills were reused because that file's hash was unchanged
(`gauntlet-mutations-pass4.json` is that prior final report). The second review
round changed `portfolio.py` and `reports.py` again (76 fresh executions,
`-pass5.json` prior); its one survivor flipped `and` to `or` in the producer
check, meaning a manifest with only one provenance field would have skipped
verification, and was killed by two new scenarios (`-pass6.json` prior). All
intermediate per-mutant outcomes remain in the adjacent JSON reports. Assertions were added rather than weakened.

The resulting BDD cases independently constrain nonnormal DSR references,
scale-safe return moments, scalar stationary-bootstrap indices/statistics,
exact daily equity returns, independent timestamp alignment, count types,
variance/overflow boundaries, and Monte Carlo interval inversion. A regression
at alpha 0.035 and 199 resamples covers binary floating-point rounding that
previously allowed a p-value equal to alpha alongside an interval excluding
zero. The high-alpha case constrains the entire attainable probability grid.

Reproduce the entire final campaign from `algo-suite`:

```sh
uv run python docs/stories/done/11-statistical-inference-corrections/evidence/gauntlet_mutations.py
```

Optional `--reuse PATH` reuses only previously killed outcomes on byte-identical
source files and reruns every survivor/error and every changed file. The runner
fails on baseline failure, undetected negative control, concurrent source
changes, surviving mutants, or inconclusive errors. Ruff and strict mypy passed
for the committed runner and Ruff passed for the added BDD steps.
